## 2. The rule that produced most of tonight's findings

**Instruments carry the defect class they hunt — now 20+ recorded instances**, several found
*inside* instruments built to catch that very class. Four tools in this environment rewrite their
own output:

| tool | what it does | consequence |
|---|---|---|
| `git log` | drops merge commits | a wrong merge-base falsifies every fence number |
| `grep` | rewrites output | reported **9 matches in 7 files** for a one-file search whose true answer was **0** |
| `cargo` | strips `0 ignored` / `0 filtered out` | **deletes the evidence the anti-vacuity rule depends on** |
| `wc -c` | miscounts | returned **0 for a 72-byte file** — the "byte-count every capture" rule was itself unreliable |

**Use absolute paths for anything load-bearing.** See `LANE-BRIEF.md` §3b and §3b-i.

**And: a known-negative assertion is self-passing on a dead instrument.** "X does not exist" is the
easiest claim to pass without doing any work, and this program has been wrong about at least three.
