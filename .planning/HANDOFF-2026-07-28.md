## 3. Standing traps, all measured, all of which have cost a run

- **`ssh SeanD@seandesktop`.** Three lanes reported the host unreachable after trying
  `sean`/`seandonahoe`/`sdonahoe`/`wayland`/`Administrator`. None exist. **Never report a host
  unreachable without trying the account the plans already use.**
- **A pipeline's exit status is the last command's.** Two lanes had a trailing `tail` steal a
  non-zero status; one reported `exit code 0` when the real status was `100`.
- **`powershell -File <missing.ps1>; exit $LASTEXITCODE` exits 0.** Guard with `Test-Path`.
- **`Start-Process` inherits the process working directory, not the PowerShell provider
  location.** A lane lost 90 minutes to a build in the ssh home dir while `Get-Process rustc`
  looked healthy — because *another lane* was compiling.
- **Windows OpenSSH kills session children on disconnect.** 1 of 600 heartbeats survived;
  under a scheduled task it ran to completion. Poll the log for an exit marker.
- **An artifact newer than its source is a build that did not happen.** `rsync -a` preserves
  mtimes; cargo then re-runs the stale binary. The dangerous direction is the false *green*.
- **`git fetch origin <branch>` does not update the remote-tracking ref** without an explicit
  refspec. This nearly caused a contract regeneration against a stale commit.
- **`fs.inotify.max_user_instances` was 128** — several concurrent lanes make ~20 `wcore-skills`
  watcher tests fail with EMFILE. Raised to 512 at runtime (resets on reboot). **A
  full-workspace run taken while other lanes build is not a measurement**; re-run the crate
  alone before reporting a regression.
- **A measurement that cannot be taken must never render as `0`.**
- **`git status --porcelain` gates are vacuous once work is committed.** Diff against the
  **merge-base SHA**, never the branch name — a branch-name diff attributes other lanes'
  merged work to you.
