## SR-27-1 — `CapabilityId`: append three tail variants

**File:** `crates/wcore-protocol/src/events.rs` — **NOT fenced**, but listed
here because it is meaningless without SR-27-2 and SR-27-3 in the SAME commit,
and because plan 27-03 will append two more variants after these three.

**Exact insertion point:** line 32, immediately after
`LegacyAutoSkillDrafting,` and before the closing `}` on line 33 of the
`pub enum CapabilityId` block that begins at line 24.

**Exact lines to add:**

```rust
    Browser,
    ComputerUse,
    Web,
```

**Order matters.** These three go at the tail in exactly this order so plan
27-03's two additions land after them on the same line and the two plans do not
conflict past the tail.

**What breaks if omitted:** the activation ladder cannot name browser, computer
use or web at all, so the honest `unavailable` + reason that OBS-06 shows
working for eight other capabilities remains structurally impossible for these
three. Criterion 2 cannot be satisfied by any mechanism currently in the tree.

No new `CapabilityReasonCode` variant is needed. The measured cases map onto
the existing vocabulary exactly: a missing browser binary is
`DependencyUnavailable`; a non-interactive session is `DependencyUnavailable`;
`[browser.policy]` denying everything is `DisabledByConfig`; a constructed but
unwired path is `RuntimePathUnwired`.

## SR-27-2 — bump the contract minor and the generator version

**File:** `crates/wcore-protocol/src/contract/generate.rs` — **FENCED.**

**Exact insertion point:** lines 24 and 25, replacing them in place.

**Current lines (measured, verbatim):**

```rust
pub const CONTRACT_MINOR: u64 = 8;
pub const GENERATOR_VERSION: &str = "wcore-desktop-contract-gen/11";
```

**Exact replacement:**

```rust
pub const CONTRACT_MINOR: u64 = 9;
pub const GENERATOR_VERSION: &str = "wcore-desktop-contract-gen/12";
```

**What breaks if omitted:** a host cannot tell that the meaning of
`capabilities.browser_suite` and `capabilities.computer_use` changed. The
adjudicated decision (`chain-plus-derived-flags`, 4-0) redefines a field
already on the wire, and the contract bump is the ONLY announcement channel for
that. Shipping the semantics change without the bump turns a declared
compatibility event into a silent one, which is the single thing the dissent
identified as unrecoverable.

**Note for whoever integrates:** if a concurrent phase also bumps
`CONTRACT_MINOR`, do NOT bump twice. One bump carries both changes; the
regenerated manifest must be produced once, from the merged tree, after both
source changes are in.

## SR-27-3 — regenerate the desktop contract manifest

**File:** `crates/wcore-protocol/contracts/desktop/v1/manifest.json` —
**FENCED.**

**Exact action:** do NOT hand-edit. Regenerate with the generator itself, from
the merged tree, in the SAME commit as SR-27-1 and SR-27-2:

```
just desktop-contract-check
```

or whatever target invokes the generator's write path in the integrated tree.

**What breaks if omitted:** the manifest is byte-exact and is compared against
the generator's output. A source change that ships without its regenerated
manifest fails `desktop-contract-check` and is a broken seam. A hand-edited
byte-exact artifact conflicts with a regenerated one in a way that is expensive
to unwind.

## What this phase did NOT need from the seam

For the record, so the integrator does not go looking:

- **`crates/wcore-config/src/compat.rs` was NOT changed and needs no seam
  entry.** Plan 27-01 directed adding a `supports_document_input` capability
  field. That field was measured to be un-gateable: `ContentBlock` has no
  document variant, documents cross the provider boundary as tool-result TEXT,
  and a gate with nothing to gate is a gate that can never fire. Reasoning and
  evidence in `27-01-INTAKE-AUDIT.md` §6.
- **`crates/wcore-cli/src/lib.rs`, `main.rs`, `wcore-agent/src/lib.rs` and
  `bootstrap.rs` were NOT changed.** No CLI subcommand was registered and no
  bootstrap publication was wired, because SR-27-1..3 must land first.
- **`.config/nextest.toml` was NOT changed.**
