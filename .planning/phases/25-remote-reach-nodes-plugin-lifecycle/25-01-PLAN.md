## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator/CLI → execution backend | A task definition, its workspace bytes and its resource request cross into a backend that may run them off-box |
| Core → remote host (SSH) | Arguments, task payload and cancellation signals cross a network boundary into a shell-capable remote environment |
| Core → cloud vendor API | A bearer credential and task material cross into a third party over HTTPS |
| plugin → execution-backend registry | A third-party plugin declares a backend spec the host will translate into real execution authority |
| backend → receipt consumer | A receipt asserting what ran, where, under what policy, is trusted by everything downstream |
