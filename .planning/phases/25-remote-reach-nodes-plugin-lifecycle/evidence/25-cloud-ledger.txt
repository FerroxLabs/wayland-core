=== THE PROVENANCE GATE — why the equivalence diff is not sufficient on its own ===
The reference task is `cat input.bin`, whose output is byte-identical to its own input. A backend
that echoed the submitted input back would produce EXACTLY the artifact digest the other three
backends produce, and `backend diff` would report EQUIVALENT while nothing ran in the cloud. That
is what the old cloud backend did. So equivalence on the reference task is necessary but NOT
sufficient, and a separate gate was required.

=== SCOPE NOTE — app-scoped, NOT org-scoped, and why ===
The credential probe asked Sean for "one throwaway Fly.io organization (or app)". What exists is
WAYLAND_F25_CLOUD_ORG=sean-donahoe, which is Sean's PERSONAL organization — not a throwaway. It is
empty today, so an org-wide emptiness assertion would pass right now, but it will not stay empty
and a future reader must not believe the org was disposable.
This lane therefore took the "(or app)" arm: it created ONE app, wayland-f25-test, and asserts
emptiness over THAT APP's machine list only. The backend's `app` field is read from
WAYLAND_F25_CLOUD_ORG, whose NAME says org and whose VALUE here is an app slug; the live runs set
WAYLAND_F25_CLOUD_ORG=wayland-f25-test explicitly. The variable is misnamed relative to its
meaning and that is recorded as FINDING 5 rather than silently renamed.
