<objective>
Prove Success Criterion 4: compromised keys, compromised plugins, compromised backends, and denied secret and egress paths all fail closed across every reference backend — with NO orphaned execution, verified by looking at the real process table after inducing each failure.

Purpose: this is where the phase either earns its claims or loses them. Plans 25-01, 25-02 and 25-03 each built a surface and proved it works. This plan attacks all three and looks underneath. The orphan half in particular cannot be closed by any suite: `crates/wcore-sandbox/src/backends/process_tree.rs` already names the only three proven tree-reaping mechanisms in this codebase — a Linux PID namespace, a Docker container reap, and a Windows Job Object — and none of the three extends across an SSH connection or into a cloud machine. Those two backends therefore start this plan with no reaping guarantee at all, and finding out what they actually leave behind is the point.
Output: an orphan scanner whose result is measured rather than assumed, a hostile fail-closed matrix crossed with every backend, and an evidence file containing the raw enumerations taken after each induced failure on Linux and on Windows.
</objective>
