<objective>
Make media generation behave the same whether it is built in, supplied by an MCP server, supplied by one that arrives after startup, or both at once — and make streaming voice interruptible, cancellable and observable in a contracted order, proved with real audio actually flowing.

Purpose: generation currently vanishes from the model's schema when its backend is unconfigured, and the engine already carries an honest-advisory mechanism built for exactly that dishonesty, complete with an anti-drift guard on the resolver probe order. What is unestablished is whether a media tool from an MCP server — especially one added after startup — is discoverable, credentialed, accounted and failed on the same terms. Separately, voice is a host-side loop across four seams with fail-loud defaults, a bounded capture ring, an idempotent cancel and a drop path that releases the device; none of that constitutes evidence that a real interruption during real playback actually stops sound, ends the turn and emits ordered events. That is the hardest live exercise in this phase and the one most likely to be quietly replaced by a unit test.
Output: a measured four-way generation comparison and a measured voice contract, both taken from the running binary; the CRITICAL and HIGH gaps closed; deterministic generation and voice corpora; and live proof including a real interruption during real audio playback, plus the honest-unavailable case on a machine with no capture device.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model schema ← capability availability | What the model can see determines what it will attempt and what it will claim it cannot do; a silently absent capability makes the model fabricate a cause |
| engine ← MCP-supplied tool | A tool definition arriving from an MCP server is untrusted input, and one arriving after startup crosses the boundary at a moment the startup snapshot has already passed |
| provider account ← generation call | Every generation call is a billed external request; an unaccounted call is spend with no record |
| filesystem ← captured audio | Recorded audio is written to disk under a validated prefix and must not survive a cancelled session |
| audio device ← session lifecycle | A capture or playback device held after a turn ends is a live microphone or speaker the user did not consent to keep open |
| host ← ordered event stream | A host drives its own UI from event order; an interruption that stops sound without an ordered termination leaves the host displaying a turn that is not running |
