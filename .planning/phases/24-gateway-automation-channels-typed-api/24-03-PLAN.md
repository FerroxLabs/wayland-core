## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chat platform → inbound dispatch | Fully attacker-controlled message content, identities, attachments and conversation identifiers cross into admission, routing and agent input |
| remote typed client → protocol server | An authenticated but potentially over-reaching caller crosses into command execution and event subscription |
| gateway state → support bundle | Configuration, credentials, adapter state and logs cross into an artefact intended to leave the machine |
| adapter configuration on disk → registry | Operator-editable files decide which adapters are constructed at start |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-03-01 | Information Disclosure | support bundle | critical | mitigate | Redaction proved by a canary sentinel seeded into configuration, credentials, environment, adapter configuration and logs, asserted absent across every member of the decompressed archive. A failure of this assertion fails the plan; it is not downgradeable to a warning. |
| T-24-03-02 | Elevation of Privilege | typed client roles | high | mitigate | Roles gate commands at the server, not the client. A refusal is a distinct named outcome from an authentication failure, and the default for an unrecognised role is deny. |
| T-24-03-03 | Spoofing | inbound channel identity | high | mitigate | Binding and routing derive the profile and agent from the platform conversation through the existing access-decision path; an unbound conversation follows a declared default rather than inheriting the last-used identity. |
| T-24-03-04 | Tampering | outbound duplicate delivery | high | mitigate | Outbound sends record and settle through the 24-01 exactly-once ledger; a retry after reconnect is suppressed at the ledger rather than at the adapter, so every adapter inherits the guarantee. |
| T-24-03-05 | Denial of Service | event cursor replay | medium | mitigate | A cursor position the server can no longer serve is refused with the oldest servable position rather than replayed from the beginning; retained history is bounded. |
| T-24-03-06 | Information Disclosure | probe and health output | high | mitigate | The probe reports whether a credential authenticated and as which identity, never the credential; health carries a reason string asserted free of secret material by test. |
| T-24-03-07 | Tampering | media normalisation | medium | mitigate | Attachment intake carries a declared size bound and an explicit degradation for an unsupported kind; an unsupported kind is named, never silently dropped. |
