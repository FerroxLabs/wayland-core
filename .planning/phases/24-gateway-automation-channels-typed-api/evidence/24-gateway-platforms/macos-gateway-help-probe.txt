Usage: wayland-core gateway <COMMAND>

Commands:
  install         Register the gateway as a per-user native service for this platform
  uninstall       Remove the native service registration
  start           Start the registered gateway through the platform's service manager
  stop            Stop it through the platform's service manager
  restart         Stop then start. A stop refusal because nothing was running is not an error here — restarting a stopped gateway is a start
  status          Report what the gateway is doing
  abandoned       List the deliveries this gateway GAVE UP on, and why
  ack             Record that you have reviewed an abandoned delivery and dealt with it
  resend          Send an abandoned delivery again, through the channel it was bound for
  support-bundle  Collect redacted health, log and configuration evidence a support engineer can act on, into a directory you can read before you send it
  drain           Close admission, finish in-flight work within a budget, and exit
  run             The long-lived runtime itself. This is what every generated service unit invokes; it is not normally typed by an operator
  help            Print this message or the help of the given subcommand(s)
