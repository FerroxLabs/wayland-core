<objective>
Make an unsupported claim mechanically impossible to publish: every claim is a record carrying a pointer to the evidence that supports it, the checker refuses a claim whose pointer does not resolve or whose scope exceeds its evidence's, and the published documents are rendered from the verified register by the same program and re-rendered on hardware so a hand edit fails.

Purpose: this is the highest-risk artifact in the program for fabrication, because every incentive runs toward the flattering sentence and the usual defense — careful reading — is exactly what three rounds of adversarial review already failed at elsewhere in this program. The defense here is that publication is a code path. A claim with no evidence row cannot be rendered; a comparative claim without a pinned baseline and a real interval cannot be rendered; a claim reaching beyond the scope of its evidence cannot be rendered; and a sentence added to a published document after the fact fails a regeneration diff.
Output: a claims module whose refusals are typed and tested, a paired adversarial corpus in which this program's own hedged sentences are the accepted controls, and four published artifacts — allowed claims, prohibited claims generated from the refusal set, limitations, and a redacted raw-evidence bundle that is refused whole if any projection carries a secret.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| published sentence ← the agent writing it | Prose is the one artifact an agent can produce without producing evidence, so publication must be a code path rather than a writing task |
| claim ← its evidence pointer | A pointer that does not resolve is indistinguishable from one that does, by reading; only resolution tells them apart |
| claim scope ← evidence scope | A scripted-harness measurement generalised to real-world use is the most plausible misrepresentation this program could make |
| classifier ← the class field | A comparative sentence relabelled factual defeats the entire mechanism unless the misclassification is itself refused |
| published document ← a later hand edit | A document that was correct when rendered can be improved afterwards, and only regeneration detects it |
| evidence bundle ← a secret in any projection | A bundle clean in four projections and leaking in the fifth is not a clean bundle |
