<objective>
Fix the comparative methodology by cross-audit before a single number exists, build a harness in which an unbounded point estimate and a one-sided comparison are both unconstructible, and run the trials against the pinned Hermes and OpenClaw baselines through one shared loopback meter that needs no credential — accounting for every leg as RUN or UNPROVEN.

Purpose: this is the plan where a frontier-review phase either earns its comparison or manufactures one. The specific forgeries available here are widening or re-choosing the methodology after seeing the numbers, reporting a point estimate that hides an interval containing zero, and letting a peer that would not install quietly vanish so Wayland's number stands alone. All three are closed structurally: the protocol is content-addressed and its commit must precede the results commit, a measurement without an interval cannot be constructed, and a comparative result without both peers cannot be constructed.
Output: a pre-registered protocol with the panel's split and dissent recorded; a trial harness whose types refuse the three forgeries; and a results document in which each of the fifteen legs is accounted for exactly once, with confidence bounds on every reported number and a named blocker on every unproven one.
