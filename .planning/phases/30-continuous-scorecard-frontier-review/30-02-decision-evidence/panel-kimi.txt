  **Q5 — Tie band: justified, and it is not double-counting — but only if you add a third verdict.**

  The two rules answer different questions. "CI of delta contains zero" is a *difference* test: it asks whether you can detect separation. A tie band is an *equivalence* test (TOST logic): it asks whether you can affirm the tools are within a practically irrelevant margin. With small n, difference tests are underpowered — wide CIs contain zero almost always — so "contains zero → tie" silently converts low power into declared equivalence. That is the real double-counting risk, and it cuts *against* rigor, not for it.

  Encodable rule, per dimension, with a pre-registered minimum practically important difference (MPID) — suggested: correctness and recovery and security δ = 0.05 proportion points; cost δ = 10% of the pooled mean:

  - **WIN/LOSS**: the delta's CI excludes zero entirely *and* its nearer endpoint exceeds the MPID.
  - **TIE (equivalence)**: the delta's CI lies entirely inside [−MPID, +MPID].
  - **INDETERMINATE**: anything else — including "CI contains zero but is too wide to fit inside the band." This verdict is mandatory; it is what keeps the tie band from rewarding low trial counts.

  **Q6 — Stop rule for a hung trial.**

  Timeout is set a priori from the pilot: `T = 5 × median completion time of the slowest tool in the pilot`, floored at 120 s and capped at 20 min, frozen in the protocol. On timeout: kill the whole process group, and score the trial as a TIMEOUT **failure in the correctness proportion — never excluded**. Excluding hangs flattens flaky tools into looking reliable; a hang is a failure the user experiences. The fixture's state at kill time is the classifier: an in-flight request awaiting a scripted response means provider-side wait (a fixture/script bug — halt and fix the harness, that trial is void); no in-flight request means the tool spun without calling the model (a genuine tool hang — counts). Abort rule: 3 consecutive timeouts for one tool halts that leg, scored FAILED-INCOMPLETE with trials-run recorded.
