Q3. **10 trials per leg.**
Because the fixture removes model sampling variance (temperature/top_p), the remaining variance is purely OS thread scheduling, filesystem I/O jitter, and network stack latency on the shared host. N=10 is sufficient to establish bounds for mechanical jitter without wasting CI compute time.

Q4. **Wilson score (proportions) and Percentile bootstrap (continuous).**
These are correct. Wilson score handles extreme distributions (e.g., 10/10 successes) gracefully where normal approximations fail, and bootstrap requires zero dependencies. Clopper-Pearson is overly conservative and will artificially widen your bounds for N=10.

Q5. **Do not double-count variance, but enforce a practical equivalence margin.**
If the 95% CI of the delta includes zero, it is a statistical tie. If it excludes zero, but the entire CI falls within a predefined trivial band (e.g., < 2% difference in tokens), it is a practical tie. Encode: `if ci_lower < 0 && ci_upper > 0 { Tie } else if abs(ci_upper) < (baseline * 0.02) { Tie } else { Winner }`.

Q6. **Wall-clock timeout threshold.**
Kill the process and record Correctness=0 if the agent exceeds 300% of the median baseline execution time, OR if it triggers the fixture's 409 `unexpected_request` violation.

Q7. **The strongest lie:** A rigid FIFO script.
If the fixture strictly expects `[Request A -> Response A, Request B -> Response B]`, and Wayland requests A then B, Wayland wins. If OpenClaw naturally requests B then A, OpenClaw gets a 409 `unexpected_request` and fails. 
**Countermeasure:** The fixture must act as a stateless or state-machine router matching on request payload invariants (e.g., "if body contains 'read_file(main.rs)', return payload X"), not a rigid FIFO queue.
