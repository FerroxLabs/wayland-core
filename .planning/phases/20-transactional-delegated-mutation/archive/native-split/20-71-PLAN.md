<objective>
Close SIX verified Windows path-representation blockers in the delegated-mutation path by replacing every ad-hoc `canonicalize` + `dunce::simplified` pair — and every place the pair was OMITTED — with ONE crate-private helper applied at BOTH storage and comparison boundaries, then prove the repair on SEANDESKTOP hardware.

Purpose: `76da033f` and `f9d5a378` correctly de-verbatimized 5 canonicalize sites (necessary — a verbatim swarm_root silently breaks the PowerShell capacity probe and git-for-Windows argv) but left 9+ sites untouched. Because `Path` equality treats `Prefix::VerbatimDisk('C')` and `Prefix::Disk('C')` as unequal, the swarm's comparison lattice split in half on Windows: `validate_swarm_root` refuses every entry point (BL-0), the isolated/integration checkout Git-authority guards always trip (BL-1), every worker dispatch is PathDenied (BL-2), a worker's own transaction root is added to its own read-deny list (BL-3), the control directory is counted as a retained worker and charged 8 GiB per admission (BL-4), and — the one fail-open — the guard keeping a delegated checkout out of the source repository never fires on the public `new_with_workspace_authority` constructor (BL-5). Normalizing only at the storage boundary is UNSOUND because `dunce::simplified` is conditional, so the fix normalizes both operands of every comparison through one deterministic helper.
Output: A centralized, drift-resistant path-representation invariant in `wcore-swarm`, invariant + security regression tests that would catch a future re-split, and SEANDESKTOP-green counts on the three baseline-failing suites.
</objective>
