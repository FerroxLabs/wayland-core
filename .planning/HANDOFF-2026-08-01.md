## 5. macOS WITHOUT THE MAC (new capability, built this session)

`hetzner-dsm` now cross-compiles Darwin:

```sh
export SDKROOT=/opt/macsdk/MacOSX15.4.sdk
export CARGO_TARGET_AARCH64_APPLE_DARWIN_LINKER=zcc-macos
export CC_aarch64_apple_darwin=zcc-macos
export CXX_aarch64_apple_darwin=zcxx-macos
export AR_aarch64_apple_darwin=zar-macos
cargo clippy -p <crate> --all-targets --target aarch64-apple-darwin -- -D warnings
```

**Works:** `check` and `clippy`. This is not a nicety — it caught a `-D warnings`
dead-code break inside `#[cfg(target_os = "macos")]` code that was failing CI's
macOS leg while the separate `Lint` workflow passed green.

**Does not work:** `nextest archive` — zig's linker SIGSEGVs on the larger test
binaries. Next thing to try is `cargo-zigbuild`.

Three gotchas already solved: zig target query is `aarch64-macos-none`; the
wrappers MUST strip incoming `--target=`/`-target`/`-arch` (the `cc` crate emits
`--target=arm64-apple-macosx`, rustc emits `-arch arm64`); and do NOT pass
`--sysroot` alongside absolute `-L`/`-I`/`-F` or they get re-rooted.

## 6. MEASURED PLATFORM FACTS — do not re-derive

One `cc`-compiled C probe, seconds to run, no cargo:

```text
getpgid(unreaped zombie)                 -> -1 ESRCH
proc_pidinfo(PROC_PIDTBSDINFO, zombie)   -> -1 ESRCH
kill(-pgid, 0)   corpse-only group       -> -1 EPERM   <- NOT discriminating
kill(-pgid, SIGKILL) corpse-only group   -> -1 EPERM
setpgid(0, <reaped, empty group>)        -> -1 EPERM   <- the safety anchor
```

Linux answers all of these for a corpse. **Darwin answers none.** That single
difference is the root of B, of G, and of the docker-gate lane's blocked
dispatch.

```text
sizeof(kinfo_proc), KERN_PROC_PID DATA query =  648   <- the real stride
the same query's null-buffer SIZE query      = 3888   <- 6x over-report
first exec of a freshly copied 241 MB binary = 26.37 s <- Gatekeeper
second exec                                  =  0.04 s
```
