# Stabilization capability contract

W15/C10 preserves the supported engine and explicit WorkflowRunner. Per-turn Consensus, SelfCritique, Hierarchical, Adaptive projections, and non-Direct classifier/mode shapes do not start independent LLM agents. They execute one Direct tool batch with a visible information message. Tool concurrency is not independent agent execution.

Network A2A is unavailable; direct embedding APIs are not a supported network route. No A2A route is added by this package.

Online system-prompt evolution is unavailable. Its compatibility configuration remains parseable but inert, and Ready advertises false. It must not spend on paraphrases, persist variants, or claim retained improvements. Functioning manual skill governance remains separate.

The DefaultScorer promotion evaluator is explicitly `structural-only`. Its score measures metadata/text conformance, not held-out task correctness. Absent execution traces do not establish zero real cost. A well-formed wrong procedure can clear structural admission; the regression makes this limitation explicit. Manual approval may use this structural evidence but cannot claim behavioral qualification. Behavioral promotion remains unsupported until the candidate is executed against held-out tasks with observed cost and an incumbent comparison.

Offline `evolution_event.retained` means provisional in-memory retention at that event. It does not assert final selection, durable persistence, promotion, or consumption. A later sibling may displace a candidate only with a higher score.

The adjacent JSON ledger is the bounded risk-ranked journey record. Missing current receipts are externally blocked, not inferred passing from source presence. The parent integration owner must attach source-bound execution receipts before changing a row to verified. Its checker validates receipt fields and current source identity; it does not execute the product or make whole-product readiness claims.

W15 execution contract: only routing fidelity, evolution availability/event semantics, structural labels and this ledger. Verification round 0 (implementation); maximum two shared rounds, run by the parent on Hetzner. Planned checks: `stabilization_capability_contract`, `stabilization_behavioral_admission`, existing `promotion_gate`, `evolve_end_to_end`, ledger checker/self-test, focused formatting and integrated caller checks. No native, live-provider, foreign-host or behavioral promotion result is asserted by this document.
