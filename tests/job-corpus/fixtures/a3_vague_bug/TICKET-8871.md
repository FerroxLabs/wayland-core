# TICKET-8871

**Subject:** saving occasionally duplicates records

Raised by: support (on behalf of three customers)

We keep ending up with the same person in the address book twice.

It isn't every time. The nightly import from the old system has never done it
as far as I can tell. It's when someone is added through the web form, or when
one of the team opens an existing person and saves them again — then sometimes
you get two of them, and the second copy has whatever was typed most recently
while the first one keeps the old details.

Four of these came in this month. One customer has the same supplier in there
three times now and their reporting is off because of it.

I couldn't tell you how to make it happen on demand, sorry. It just does it
sometimes.
