# Helper-attributed env-global hazards that predate the widening of
# scripts/check-test-env-globals.py (FerroxLabs/wayland#1134 c3).
#
# ── WHY THIS FILE EXISTS ────────────────────────────────────────────────────
#
# Until 2026-08-29 the lint fired only on a `set_var` written lexically inside
# a test fn. The identical write moved one call deep -- into an RAII env guard,
# a `temp_state()`, a `stub_npm_on_path()` -- was classified `helper` and
# excused, 153 sites of it, including `PinnedRetryBudget::pin`, the helper
# #1134 opens with. Resolving callers turned that excuse into a verdict, and
# the verdict named nine pre-existing pairs on the day it was written.
#
# Eight of them are listed below and are owned by FerroxLabs/wayland#1233.
# They are DEBT, not clearance: each is a real
# hazard under the shared-process CI leg, where one test binary is one process
# and a sibling test's production path reads what the guard wrote. They are
# listed rather than fixed here because fixing them means changing the tests
# themselves, in crates this change does not otherwise touch, and a gate that
# goes red on the day it lands is a gate someone switches off.
#
# ── WHAT A LINE HERE DOES AND DOES NOT DO ───────────────────────────────────
#
# A listed pair is REPORTED loudly on every run and does not fail the gate.
# Everything else fails. Three rules keep the list from rotting, all enforced
# by the gate itself:
#
#   * A pair whose write is DIRECT -- inside the test fn -- is never exempt,
#     whatever this file says. The exemption covers only the class the lint
#     could not previously see.
#   * An entry past its expiry fails exactly as an unlisted pair does.
#   * An entry that no longer matches anything fails as STALE. The list is
#     designed to shrink, and a line that has quietly stopped applying is a
#     line that would excuse the next occurrence for free.
#
# ── FORMAT ──────────────────────────────────────────────────────────────────
#
#   <YYYY-MM-DD expiry>  <test-binary>  <ENV_VAR>  <gh#NNNN>  <reason...>
#
# Whitespace-separated; the reason is the rest of the line and is MANDATORY.
# The binary id is what the gate prints: `<crate>` for a lib test binary,
# `<crate>::<target>` for an integration one.
