# Every production site that could answer "which host does this URL reach?",
# and what each one actually does. Owned by FerroxLabs/wayland#1276.
#
# ── WHY THIS FILE EXISTS ────────────────────────────────────────────────────
#
# `wayland#1211` -> `#1243` -> `#1252` is ONE bug class arriving three times: a
# hand cut takes everything up to the first `/` and then the last `@` part, and
# each cut missed a different separator. #1252 closed its three sites by
# READING all 24 production lines carrying the scheme separator and
# dispositioning each. That was a measurement, and a measurement is a snapshot:
# nothing went red when a FOURTH cut was added.
#
# `scripts/check-url-authority-cuts.py` turns that snapshot into a standing
# gate. It enumerates the same total syntactic set, plus a second one that sees
# a cut carrying no scheme literal at all, and refuses any member this file
# does not classify.
#
# ── WHAT A LINE HERE DOES AND DOES NOT DO ───────────────────────────────────
#
# A line is a CLASSIFICATION of one site, not permission for a class. It is
# keyed on `<path>::<fn>` PLUS a fingerprint of the site's own text, so:
#
#   * A second cut added to the same function is a NEW site with a new
#     fingerprint and reds the gate with this line still sitting here.
#   * Changing a classified site changes its fingerprint, so the line goes
#     STALE and the gate fails until somebody re-reads the code. A cut cannot
#     be edited into a decision under cover of an old disposition.
#   * A line matching nothing fails as STALE. The list is designed to shrink.
#   * A line whose reason is missing or shorter than 25 characters is refused
#     as unparseable rather than read as an exemption.
#
# A host-shaped function that reaches `url::Url` / `wcore_types::url_authority`
# needs NO line: the gate reads the call itself. Hand-copying that fact here
# would only give it somewhere to rot.
#
# ── THE CLASSES ─────────────────────────────────────────────────────────────
#
#   parser     answers through url::Url / wcore_types::url_authority
#   no-host    derives no host from a URL string at this site
#   display    cuts a host, but only to render it -- decides nothing
#   test-only  #[cfg(test)] code; ships in no binary an operator runs
#
# The first three are wayland#1276 c3's own three. `test-only` is the fourth
# the enumeration forced: #1252's sweep excluded `crates/*/tests/` but four
# scheme-separator sites live in `#[cfg(test)]` modules inside `src/`, and
# calling those "returns no host" would be false -- they do cut a host out of
# the bundled `providers.toml`. Naming what they are beats mislabelling them.
#
# ── FORMAT ──────────────────────────────────────────────────────────────────
#
#   <class>  <path>::<fn>  <fingerprint>  <reason...>
#
# Whitespace-separated; the reason is the rest of the line and is MANDATORY.
# `<fn>` is `<module>` for a site at module scope, e.g. a doc comment. The
# fingerprint is printed beside every finding and by `--list`. Line numbers are
# deliberately not part of the key: they drift on unrelated edits.
